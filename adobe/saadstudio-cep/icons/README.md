# Icons

Drop a square `logo.png` (recommended 48×48 or 96×96) into this folder.
The CEP manifest at `../CSXS/manifest.xml` references it as the panel icon
for both panels (main + draw-to-edit).

If you re-use the existing brand mark from
`adobe/EditPilotUXP/logo-saad.png`, just copy that file here and rename
it to `logo.png`.
