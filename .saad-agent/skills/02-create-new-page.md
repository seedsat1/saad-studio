# Create New Page Skill

## Workflow
1. Determine exact route path in Next.js App Router (e.g. `app/(dash)/(routes)/new-page/page.tsx`).
2. Create page component and link to navigation / sidebar.
3. Apply Saad Studio brand UI (Dark Glass, Deep Blue + Subtle Gold).
4. Connect to API backend if applicable.
5. Save generated outputs to Gallery system.
6. Implement loading, error, and empty states.
7. Verify mobile responsiveness and ensure zero regressions on legacy pages.
